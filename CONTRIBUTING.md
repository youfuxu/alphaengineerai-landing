# Contributing to MindDividend Shield

MindDividend Shield is a free, safety-first first check for suspicious messages. The project is designed for people in different countries and languages, so practical translation and clarity improvements are welcome.

## Helpful contributions

- Correct a translation so it sounds natural to local readers.
- Add a scam pattern that is common in a region or messaging platform.
- Improve a safety explanation without making promises that a first-pass checker cannot prove.
- Report a broken link or accessibility problem.

## Privacy rule

Never include real passwords, payment details, verification codes, identity documents, private addresses, or private screenshots in an issue or pull request. Use a fictional or fully redacted example.
